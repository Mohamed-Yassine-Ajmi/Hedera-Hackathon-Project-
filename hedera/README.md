# Hedera Layer Integration

Dedicated Hedera Hashgraph blockchain integration module for the project.

Please refer to [`hedera/README.md`](./hedera/README.md) for full architecture and usage documentation.

### Quick Commands

```bash
# Compile and validate TypeScript types
npm run typecheck

# Build module
npm run build

# Run unit tests
npm test

# Run setup diagnostic check
npm run setup

# Run API demo
npm run demo
```
